# Batalha Naval em Python

Projeto de estudo de programação orientada a objetos, desenvolvido por Pedro Alvimm seguindo seu manual de Batalha Naval.

## Executar

Com Python 3 instalado, execute na pasta do projeto:

```bash
python batalha_naval.py
```

As dependências utilizadas fazem parte da biblioteca padrão do Python.

## Arquivos

- `batalha_naval.py`: ponto de entrada do programa.
- `jogo.py`: classes, regras, ataques e posicionamento de navios.
- `interface.py`: menu, interface de terminal e histórico de partidas.
- [Guia de estudo](docs/Guia_de_estudo_Batalha_Naval.docx): código explicado, glossário e revisão para apresentação.
- [Manual original](docs/Manual_Batalha_Naval_V2.pdf): manual usado como referência na construção do projeto.

## Observações

O histórico é criado localmente em `historico.json`. Atualmente, as opções médio e difícil compartilham a mesma estratégia de tiros.
